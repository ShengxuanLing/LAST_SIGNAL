# GDD-03 — 首切片关卡设计（Station Zero · The Broken Door）

> **性质与边界**：本文件是**设计规格，不是实现**。提案不因交付升为批准，设计不以实测结论冒充实测；所有新增细则仅为**建议/候选**，沿用 GDD-02 未批准标记（`建议冻结`、`原型调参初值`），不扩大冻结、不声称已实现/已验收。
> **权威引用**：RER、VSCC、`GDD_02_TEST_SPEC.md`、`VERTICAL_SLICE_EXPERIENCE_FLOW.md`、`ECHO_VERTICAL_SLICE_SCRIPT.md`、`VERTICAL_SLICE_UI_SPEC.md`。
> **坐标约定（严格区分）**：**地形 mask 用整数 cell `(i,j)`**；**所有实体/设备/端点用 position `(i+0.5, j+0.5)`（格中心）**。1 格 = 1 tile = 64 px；玩家半径 0.5、敌人 0.5、Boss 3.0 格。
> **速度修正（取代早期前提）**：`Player.update` 用 `sx/32`、`sy/16` 转换到 `vx/vy`，**方向相关、非恒定**；`220/64 = 3.4375 格/秒` 仅作**保守时间下界**（时长为上界），冲刺亦非恒定 1.29 格。所有时间为设计期上界，**不声称已验证可玩**。
> **死亡/过房铁律**：死亡 `finishRun(false)` 清本局 run、新开 R0；仅手动退出/刷新恢复最近成功 checkpoint；**过房由切片专用状态门控触发，不复用 `World.placePortal` 清房传送门，禁止任何绕谜题旁路；过房保留 HP/位置，不 reset 满血**。

## 0. 批准层级（不笼统宣称「已批准」）

D1/D2 = **【明确批准】**（必击败 Warden / 常规战斗独立可胜 / Signal 有可测量收益 / 无绕 Boss 撤离；仅门·中继器·预设桥·敌人感知四类目标）；D4 = **【仅原则批准】**；D3/D5/D6/D7/D8/D9 = **【仅原则认可】**。其余细则为 `建议冻结`，数值 `原型调参初值`，待用户签核。

## 1. 单位、LOS 与坐标

- cell `(i,j)` 整数 → 地形墙/地板/门孔/桥覆盖；position `(i+0.5,j+0.5)` → 实体/设备/安全点。
- 玩家速度下界 3.4375 格/秒（非恒定）；drone `aggroRange` 5.3125 格、`attackRange` 3.125；boss `aggroRange` 99999、`attackRange` 3.125。
- 能力：Scan 半径 12/耗 10/CD 2s/揭示 8s；Jam 半径 6/耗 25/**单目标**/持续 6s/CD 8s；Decoy 施法+接收半径 5/耗 20/持续 8s/CD 10s；桥建立预警 `WARN=1.5s`。全部**严格 `<` 半径**。
- LOS：`World.tileAt()`/`isWalkable()` 只读 `tile.type`，supercover、去端点、墙角两侧格都查；阻挡 `wall/lava/water`（chasm 归 `lava`，桥 `STABLE` 时该覆盖层可走）。
- 输入（UI 规格 §2）：`Z` Scan、`X` Jam（目标预览）、`C` Decoy（落点预览）；保留既有键位。

## 3. R0 — 苏醒舱（start）

- **目标**：移动/瞄准/开火/冲刺 + 一次短基础战斗；首次 Scan；ECHO 首次观察。
- **首次信息/未知**：出口控制面显示两条苏醒标记「本次 T+00:00」与「存档 T+17:00」；首次 Scan 在无威胁位置揭示「指示灯熄但接收器仍有载波」；异常**只经设备记录**呈现，**无第五类可操纵目标**；不冻结年代/轮回/ECHO 身份。
- **ECHO**：`ECHO_CONTACT`/`ECHO_R0_ANOMALY`，只比较本地记录、表达无法解释。
- **网格 18×12**，地形 mask：边框墙；掩体柱 cell `(5,3)(5,8)(12,3)(12,8)`。
- **位置**：出生 `S(9.5,6.5)`；出口设备 `R0_D_EXIT(16.5,6.5)`（无 SEAL）；drone `E1(4.5,4.5)`。
- **敌人（仅现有种类）**：1×drone。
- **有向连接**：`R0_D_EXIT` 开启且到门位 → R1 入口 `(1.5,9.5)`。
- **检查点/失败**：出生区 cleared（无活敌）/alive 时可 `captureCheckpoint`；死亡 `finishRun(false)` 清 run、新开 R0。
- **完成**：清 `E1` 后开普通门进入 R1。**预算**：≈4min / 1–2min。

## 4. R1 — 观测实验室（combat / 固定模板）

- **目标**：九步因果链（VSCC §2 / RER §4.1 / `G2T-E-01`）。
- **完整封闭 mask（整数 cell）**：边框墙；**竖直隔断墙 `x=10` 贯通 `y=1..12`**，仅在 door 孔留空；**水平隔断墙 `y=5` 贯通 `x=11..21`**（把东侧分为北小室与南走廊）。门孔 2 格由门体**整格占满**，旁边不可穿：
  - 西入口区：`x1..9, y1..12`。
  - `R1_D_REF` 门孔 cell `(10,2),(10,3)`（2 格全占），东侧为**北小室** `x11..21, y1..4`（死路，被 `y=5` 墙封闭）。
  - `R1_D_SEAL` 门孔 cell `(10,9),(10,10)`（2 格全占），东侧为**南走廊** `x11..21, y6..12` → R2 出口。
  - 因此西入口到南走廊**只能经 `R1_D_SEAL`**；北小室只能经 `R1_D_REF`；`y=5` 墙与 `x=10` 墙 + 边框保证无绕行。
- **设备/端点（position）**：`R1_D_REF` 门体覆盖 cell `(10,2),(10,3)`，其**接收器**在 `(10.5,2.5)`；`R1_D_SEAL` 门体覆盖 `(10,9),(10,10)`，其**接收器**在 `(10.5,9.5)`；`R1_SRC_SEAL(12.5,9.5)`（cell `(12,9)`，**只读模板发射源**，玩家不可 Jam/不可免费断源，仅 Scan 可读的发射端点）。**Jam 目标是 `R1_D_SEAL` 的接收器 `(10.5,9.5)`，不是 source**。**门是动态可通行 overlay，不是封锁 LOS 的静态墙**；封门时 Scan 仍按 RER LOS 看到只读源，按已发现端点权限裁剪，不读全图。入口 `(1.5,9.5)`；R1 出口/R2 触发点 `(20.5,9.5)`。
- **九步（坐标绑定，Scan 非 Jam 前置）**：① 试两门（对照开 / 谜题 `E_LINK_UNAVAILABLE`）→ ②（可选）Scan（−10）揭示谜题门接收与合法连接 → ③ 提假设（假设/事实分离）→ ④ **对谜题门接收器 Jam**（−25，单目标，发射源仍在）→ ⑤ `JAMMED_OPEN` 真实通行 → ⑥ 通过（门区权威位置快照）→ ⑦ 到期恢复接收、源仍在才重 `SEALED` → ⑧ 当前设备求解（`SAFE_PENDING_CLOSE`/按意图）→ ⑨ 验证理解（预测到期/占位/断源 + 同构迁移）。
- **过门后不即载 R2**：合法过门只置 `passedSealThisVisit=true`，玩家仍留**南走廊**；Jam 到期只重算门态，**不把已过门玩家锁在南侧、不清除 `passedSealThisVisit`**；须走到出口 `(20.5,9.5)` 才转 R2。南廊安全静止时**自动安全 checkpoint**（无活敌/安全位置；「无危险转换」为未来规则，非当前源码条件）。
- **R1_SOURCE_TEST（新增提案，未批准）**：仅当玩家已合法过门（`passedSealThisVisit=true`）且在南走廊**出口前安全侧**时，安全条件下模板源 OFF 两逻辑秒再 ON；**可选、不门禁、不强迫等候**（不强制等自检才可离开）、非玩家免费断源；进房间快照，安全点不重复制造事件。
- **敌人**：无。**检查点/失败**：入口区 cleared 可 `captureCheckpoint`；过门后南廊安全静止可**自动安全 checkpoint**；`SEALED` 手动开门 `E_LINK_UNAVAILABLE` 零扣费；到期不夹人、不锁已过门玩家。
- **完成**：Jam 门接收器 → 过门（`passedSealThisVisit=true`，仍留南廊）→ 到达出口 `(20.5,9.5)` 才转 R2。**预算**：≈5min / 1–2min。

## 5. R2 — 失稳走廊（combat / 固定模板）— 采用 Lead 推荐布局

- **网格 26×14**。地形 mask（整数 cell）：边框墙；西地板 `x1..9,y1..12`；东地板 `x16..24,y1..12`；**chasm（`lava`）`x10..15,y1..12`**；**桥覆盖层 `x10..15,y8..10`（6 长 × 3 宽，仅 `STABLE` 可走）**。无其它内部墙。
- **位置（格中心）**：入口 `(2.5,10.5)`；**1 个 guard `(5.5,6.5)`（drone）**；near relay `(8.5,9.5)`（`R2_RELAY`/`R2_CTRL_NEAR`，初始 OFF、西岸自供电、手动 0 费）；far control `(18.5,9.5)`（`R2_CTRL_FAR`）；**固定安全岸点** `SAFE_W(9.5,9.5)`、`SAFE_E(16.5,9.5)`（仅供桥失败回岸，**非 checkpoint**）。
- **两条解（均到东岸 `(16.5,9.5)` 触发 R3）**：
  - **路线 A（清敌）**：清 guard → near 开 relay（0 费）→ 桥 `TRANSITIONING`(1.5s)→`STABLE` → 过桥到 `SAFE_E`。不耗 Signal Energy。
  - **路线 B（留敌 + 单次 Jam 抑制，稳健）**：从**实际入口 `(2.5,10.5)`** 起；对 guard 的 Link **单次 Jam**（入口→guard 距离 5.0 < 6，单目标 −25）→ guard 只调查旧位置证据、不追实时位置 → 行至 near `(8.5,9.5)` 开 relay（**relay 开不覆盖/不刷新该次个人 Jam**）→ 桥 1.5s 建立 → 过桥到 `SAFE_E`。**成功必须在东岸 `(16.5,9.5)` 触发，不走额外远路。**
  - **设计期算术（保守下界 3.4375 格/秒，非恒定；仅为上界自检，不声称已验证可玩）**：entry→near `6.083` 格 = `1.770s`；+建桥 `1.5s`；near→`SAFE_E` `8.0` 格 = `2.327s`；合计 `5.597s`（上界）< 单次 Jam `6s` 窗口。**运行期验收时限：从单次 Jam 生效起到到达 `SAFE_E(16.5,9.5)` ≤ 6s；否则路线 B 失败**（待实现 E2E 验收，不是现状承诺）。
- **不保证事项（如实）**：guard 已出手攻击不回滚；player 可能受伤；**不保证无伤**。Jam 只抑制新信息、guard 调查旧位置；若玩家进入其当前可见且 Jam 已过期，则可见玩家优先（RER §4.4）。**Decoy 仅为可选实验**，不声称必定转移可见玩家。
- **桥失败**：送「进入桥前最后一岸」对应固定点（`SAFE_W` 或 `SAFE_E`），扣 `BRIDGE_DANGER_HP=20`，**不总送西岸**；死亡按正常失败清 run、新开 R0；无次数上限、无 `RECOVERY_MAX`。
- **有向连接**：桥 `STABLE` 且玩家到 `SAFE_E(16.5,9.5)` → R3；**不用清怪门禁**（B 不被「清怪才产生传送门」挡）。
- **检查点**：R2 有活 guard（路线 B）时**不可 `captureCheckpoint`**；**B 的最近安全为 R1 出口**（不是 R2 安全岸点）。路线 A 清 guard 后才可能满足 checkpoint 条件（见 §8）。
- **预算**：≈6min / 2–3min。

## 6. R3 — 共识核心（boss）

- **网格 26×18**；地形 mask：边框墙；掩体柱 cell `(7,4)(7,13)(18,9)`。
- **位置**：入口 `(1.5,9.5)`；`R3_WARDEN(13.5,9.5)`（半径 3.0，三阶段 `0.66/0.33`、`Math.max(2,dmg*reduction)`，**复用现有 Boss**）；`R3_SHIELD_RELAY(20.5,4.5)`（维护封闭，普通交互 `E_NOT_APPLICABLE`）；玩家 **Jam/Scan 阵地 `(20.5,7.5)`**。
- **敌人**：`R3_WARDEN`。**phase2 `summonDrones()` 会召唤 drone（沿用现有 `Boss.summonDrones`，其 `Math.random()`→种子源是未来适配提案，本轮不强作）**，故**不写「无其他敌人」**；普通路线零 Signal 仍可胜（`G2T-M-06`）。
- **到阵地 `(20.5,7.5)` 的具体可行路径（已验证 cell 可走、避开 Boss 半径 3 与掩体）**：`(1.5,9.5) → (1.5,2.5) → (20.5,2.5) → (20.5,7.5)`；路径 cell 全部可走，路径到 Boss 中心最小距离 `7.0 > 3`；`(20.5,7.5)` 到 Boss `7.28 > attackRange 3.125`。**不写「任意站位可达」**，只给这条具体路径。
- **普通路线**：直接射击至 `boss._hp≤0`（护盾 ON 仍每击 `≥2`）。
- **Signal 路线**：在 `(20.5,7.5)` 对 `R3_SHIELD_RELAY(20.5,4.5)` **玩家** Scan 揭示（距离 `3.0 < 12`、LOS 通，**Scan 由玩家发出，非 Boss**）→ 同站位 Jam（`3.0 < 6`、LOS 通）→ 护盾倍率 `0.5→1.0`；配对 20 击护甲后单次 20 ⇒ ON 200 / OFF 400（`G2T-M-07`）。
- **有向连接/出口**：`boss._hp≤0 && player.alive` ⇒ `won=true` → R4；无绕 Boss 撤离、无谜题门出口；同 tick 双死失败优先。
- **检查点/失败**：含 Boss ⇒ 不可 `captureCheckpoint`；死亡 `finishRun(false)` 清 run、新开 R0；暂停/菜单 `World.update` 早退、sim 冻结、不回滚；**仅「全清且无活敌、Boss 生成前」可安全写 checkpoint**；有活敌（含 phase2 召唤）无 R2 checkpoint。
- **预算**：≈7min / 4–5min。

## 7. R4 — 结尾界面 / 撤离表现（UI，无网格）

- **触发**：R3 胜利后进入（不是额外战斗房）。
- **二选一不透明持久选项（D7 / RER §11.4 / UI 规格 §8）**，值域 `NONE | POWER | MEMORY`（ECHO_SCRIPT §5），**本任务即定义**：
  - `POWER`：保存成功 → 系统灯断续变稳定、记忆页标「未保留」；下局 R0 稳定灯带 + 出口设备公开「供电已稳定」记录。
  - `MEMORY`：保存成功 → 档案校验完成、灯带仍断续；下局 R0 档案页多一条可读保留记录（内容仅「记录校验完成。来源标识仍不可解析。」）。
  - `NONE`：首次未选，控制台保持未提交。
  - 两候选并列展示即时代价、下局可观察后果与 ECHO 观点（ECHO 倾向 MEMORY 但接受任意选择，不代选、不降权限）。
- **保存状态机**：`PREVIEW→CONFIRM→SAVING→COMMITTED|SAVE_FAILED`；失败 `E_SAVE_FAILED` 保留界面可重试、不伪报；同局同选项重试沿用事务 ID；下一局可再选并替换唯一持久结果；独立命名空间 `last_signal_station_zero_save_v2`，不读原 run、不自动升 `SAVE_VERSION`、不覆盖主/economy 档。
- **预算**：≈2min / 1–2min。

## 8. 安全岸点 vs checkpoint（现状 / 未来前置分开）

- **安全岸点（bridge recovery，非 checkpoint）**：`SAFE_W(9.5,9.5)`、`SAFE_E(16.5,9.5)`仅用于桥 `UNSTABLE` 到期把玩家送回「进入桥前最后一岸」并扣 20HP。它们**不是存档检查点**。
- **checkpoint（`SaveSystem`/`RunCheckpoint`）——现状源码事实**：`captureCheckpoint` 仅在房间 **cleared / alive / `!won` / `!boss` / 无活敌** 时写入并记 `rngState`（`src/world/World.ts:674-688`）。**「无危险转换」不是当前源码条件**（那是 GDD-02 的未来提案，未实现），本文不把它写成现状。
- **各房间现状**：R0 清场后可写；R1 入口清场后可写，过门后南廊安全静止可**自动安全 checkpoint**（`passedSealThisVisit` 不因 Jam 到期清除）；R2 **有活 guard（路线 B）时不可写，最近安全为 R1 出口**；路线 A 清 guard 后（且无活敌、Boss 未生成）可写；R3 含 Boss 不可写，死亡回 R0。**仅手动退出/刷新恢复最近成功 checkpoint**；无战斗内快照。**「无危险转换」为未来规则，不是当前源码条件**。
- **未来前置（未批准/未实现）**：切片独立命名空间、`reality` 扩展、`sliceSchema/templateId/templateRevision` 判别、迁移/回滚、`E_NO_FAR_SHORE` 装载期校验——均属 ADR-06 待定，**不自称已支持**。
