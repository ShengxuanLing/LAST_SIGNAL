## 0. 共同前提（三个方向都必须满足）

**公平比较**
- 三张游戏画面概念（A1 / B1 / C1）使用**同一房间、同一相机、同一战斗瞬间**：
  - 14×12 房间；
  - 执行者位于 (6,7)，drone 位于 (10,3)，stalker 位于 (11,8)，hunter 位于 (3,3)；
  - 中继器 R-2 (2,1) 向门接收器供信号；
  - 场景中有扫描脉冲和一句 ECHO。
- 因此比较的是美术方向，而不是构图运气。

**玩法优先**
- 不改变等距 64×32、碰撞、房间尺寸、相机缩放区间和任何数值。
- 角色贴图可以变大，但不能超过碰撞半径太多：可视主体不超过碰撞足迹宽度的约 1.2 倍（规范见 03 §4）。

**技术基础**
- 必须能在 `Phaser.CANVAS` 下实现，原因见 01 §3.3：FX 与 Light2D 都只支持 WebGL，而 ADD / MULTIPLY / SCREEN 混合与粒子在 Canvas 下可用。
- 主要手段：离屏 Canvas 烘焙纹理、少量逐帧 Graphics、混合模式、粒子。

**世界观约束**
- 不改 GDB 中的任何事实。敌人起源只采用 01 §2 中的"合理推导"，作为造型语言，不写成剧情事实。

**社区角色**
- 鲸鱼娘等五位角色必须能放进画面，且不修改原图（授权约束）。
- 每个方向都给出"接入规则"：接触阴影、描边、色调映射，均在 03 视觉规范中落实。

**素材来源**
- 不使用任何来历不明或商业素材。样稿全部手写 SVG，字体只按名称引用系统字体，不分发。

## 1. 方向 A · SURVEY INK 观测墨线（推荐）

**样稿**：`art/concepts/A_survey_ink/A1_screen.svg`、`A2_silhouettes.svg`、`A3_palette_material.svg`、`A4_hud.svg`

### 1.1 核心概念

**"被观测到的世界才被画出来。"**

- 设施本体是石墨色的体块：涂装钢、浇筑混凝土，用明度表达空间。
- 执行者与 ECHO 已经观测过的部分，被一层精确的**骨白测绘墨线**"勘测"出来：网格、板缝、尺寸线、引线标注、编号。
- 尚未观测的区域只剩下体块，没有墨线。
- Scan 不是叠加上去的特效。它是一次"测绘行为"：脉冲环扫过的地方，墨线被画出来，标注随之出现。

### 1.2 世界观契合

| GDB 依据 | 视觉回应 |
| --- | --- |
| 核心循环"观察 → 假设 → 实验"[§1.3] | 观察 = 墨线出现；假设 = 虚线标注（ECHO"推测"）；实验结果 = 实线标注 |
| 零号站的职责是观测与保存知识 [§2.5] | 测绘、档案的视觉语言：尺寸线、编号、标签、手册式 HUD |
| 双重认知：人类看实体，ECHO 看信号 [§4.3] | 体块 = 人类可见的物理世界；冷蓝信号线与标注 = ECHO 的信号视角；两层可以分别开关 |
| 敌人是仍在执行失效指令的设施系统（**推导**）[§2.4] | 敌人取材于设施仪器：经纬仪无人机、夹持爬行体、测距风筝、闸门塔、浑天仪 Warden |
| 神秘感来自尚未理解的规律 [§2.2] | 未被画出的黑暗不是随机的雾，而是"尚未测绘" |
| 多次苏醒 [§3.3] | 磨损采用"反复触碰处露底变亮"的规则，编号 `EX-17` 也有磨损 |

### 1.3 色彩

用明度区分阵营，用色相表达含义（详细 Token 见 03 §2）：

| 角色 | 颜色 |
| --- | --- |
| 环境 | `#15191D` |
| 阴影 / 未观测 | `#07090B` |
| 执行者 / 已知墨线 | 骨白 `#E8E2D0` |
| 敌对 | 朱红 `#FF4A3D`，只用于敌对光圈与敌弹 |
| 未知 / 不稳定 | 琥珀 `#F2A93B` |
| 稳定信号 | 冷蓝 `#7FB7FF` |
| 可交互协议 | 青 `#4FE3D6` |
| 稀有 | 荧绿 `#9FE870` |
| 高优先观测 | 纯白 |

- 对 `#07090B` 的手算 WCAG 对比度：骨白 11.2、青 12.6、冷蓝 9.6、琥珀 10.0、朱红 6.0、荧绿 13.5。
- 敌对与稀有的明度不同（L 0.27 对 0.66），形状也不同，以应对红绿色觉差异。

### 1.4 角色造型

- **执行者**：画面里明度最高的块。骨白硬壳工作服，左侧有扫描桅杆加青色灯，右手持枪，构成不对称识别。
- **敌人**：深色体块，各带**唯一一个朱红光圈**（"感知器官"）。五类轮廓各不相同（A2 灰度测试）：三脚、低宽、悬浮菱、竖碑、环。
- **Warden**：浑天仪。环上的冷蓝节点 = 护盾，阶段推进时环逐一脱落，阶段可读。
  - 与 GDB §8.4、§11.7"护盾与 Signal 关联"一致。
  - 具体机制以实现为准；当前代码只有 HP 三阶段，美术只表现已实现的部分。

### 1.5 场景结构与材质

**结构**
- 墙体加高到约 90px，厚度可读，带结构肋。
- 地板板缝每 4 格一道重缝。

**材质**
- 涂装钢（边缘磨损露底）、浇筑混凝土（渗水痕）、地板加墨线、敌对光学镜、执行者外壳、中继发射口。
- 全部可以用 Canvas 程序化烘焙：渐变 + 噪声 + 刻线 + 剥落遮罩。

**房型识别**
- 靠设施功能道具与墙面喷码区分，例如 `Z-07 OBS`、`COLD STORE 3`。
- 视觉 RNG 使用独立种子（03 §9）。

### 1.6 灯光与氛围

**五层明度**：未观测虚空 → 环境体块 → 墨线 / 主光边 → 自发光 → 闪光。

- 光不再锁定在屏幕中心，而是来自世界：
  - 玩家桅杆灯（青色，小半径）；
  - 中继器（冷蓝）；
  - 敌对光圈（朱红点光）。
- 光用 ADD 混合的烘焙光斑实现，Canvas 支持。

### 1.7 UI

- "野外测绘手册"风格：发丝框、角标、等宽数字、分段生命条、Signal 能量条带 Jam 阈值刻度。
- ECHO 的三类信息用线型区分：观察 = 实线，推测 = 虚线，历史 = 点线。颜色之外还有冗余编码，对应 GDD-03 UI §3。
- Station Zero 的 DOM HUD 与主游戏 HUD 共用同一套 Token（AR-05）。

### 1.8 Signal 表现（按已实现机制）

| 机制 | 表现 |
| --- | --- |
| Scan | 等距圆脉冲：虚线环、刻度，被扫过的区域显出墨线 |
| 信号连接 | 冷蓝虚线 + 方向箭头，从源指向接收 |
| Jam | 接收端出现"截断"符号，连接线断续 |
| 过期 | 墨线褪成点线（历史） |
| 敌人感知 | 朱红虚线瞄准线，只在合法揭示时显示 |
| Energy | 能量条在 25 处有刻度（一次 Jam 的费用） |

全部映射到 Station Zero 已有的状态（`SEALED / JAMMED_OPEN / ACTIVE / UNSTABLE` 等）。

### 1.9 成本与扩展

- **成本**：中等。环境与角色全部程序化，与现有 `GraphicsFactory` 和 `WorldRenderer` 管线同构；主要工作量在形体设计与动画帧。
- **扩展**：新区域（城市、档案馆、核心网络）只需替换"体块材质"，墨线规则保持不变，品牌延续性最强。
- **风险**：
  - 墨线过细，在密集战斗中会变噪声。缓解：墨线只出现在环境层，强度随战斗降低；角色靠体块明度识别。
  - "测绘 / 蓝图"容易被误读为蓝图风。缓解：禁用蓝底白线，改用石墨底骨白线，并配合设施喷码。

## 2. 方向 B · BRUTALIST RELAY 粗野中继

**样稿**：`art/concepts/B_brutalist_relay/B1–B4`

### 2.1 核心概念

**"人在巨型基础设施里极其渺小。"**

- 木模浇筑混凝土、氧化钢与铜绿、钠灯暖色工作光池、物理电缆槽。
- 信号以光脉冲的形式沿电缆移动。墙高 150px，有前景管道遮挡，有远处巨构剪影。

### 2.2 契合度

- 对应 GDB §12.1 / 12.2 的"宏大、巨型基础设施、低照度工业环境、深空中继站"，契合度高。
- 对"观测 / 认知"主题只有间接表达：信号是物理的，而不是"被理解的"。

### 2.3 要点

| 项 | 内容 |
| --- | --- |
| 色彩 | 混凝土 `#3A3A37`、作业白 `#E9ECEA`、敌对 `#E8452C`（4.7:1，偏低）、中继信号 `#CFE8FF`、铜绿交互 `#5FD3C4`、黄铜稀有 `#D8B25A`、钠灯 `#FFB347`（非语义环境光） |
| 角色 | 方块工装、电池背包；敌人是巡检旋翼、液压抓取机、吊舱、冲压塔、中继龙门 Warden |
| 场景 | 厚重体量、格栅沟、警示斜纹、桶与倒车、前景遮挡层 |
| 光 | 钠灯暖光池对冷信号，冷暖对比最强 |
| UI | 冲压钢铭牌、倒角板、窄体无衬线、喷码数字；占屏约 9%（A 约 5%） |
| Signal | 电缆中的脉冲；Jam 等于"切断电缆段"，非常直观 |

### 2.4 成本、扩展与风险

- **成本**：最高。高墙要求处理遮挡与透明度，前景层需要按玩家位置淡出，道具资产量大。
- **扩展**：每个新区域都需要大量新布景。
- **风险**：
  - 最容易滑向"通用工业科幻"。辨识度依赖布景内容，而不是可复用的视觉规则。
  - 暖色同时承担环境光、警示、稀有三种含义，语义拥挤（B3 已标注）。
  - drone、stalker、sentinel 同属"工业方盒"轮廓类，分辨度弱于 A（B2 已标注）。

## 3. 方向 C · CONSENSUS GHOST 共识残影

**样稿**：`art/concepts/C_consensus_ghost/C1–C4`

### 3.1 核心概念

**"共识失败 = 印刷失准。"**

- 暗场中一座瓷白、临床的实验室，被单一顶光照亮。
- 状态未达成共识的物体，被以 C / M / Y 三张"印版"错位印出，**位移量等于不稳定程度**。
- 信号表现为网点密度；执行者是唯一永远对齐的图形。

### 3.2 契合度

- 与"共识场 / 状态重叠 / 相互矛盾的历史"[GDB §2.1, §2.4, §12.4] 的隐喻最直接、最原创。
- 能直接回应 GDB §12.4 列出的"结构轮廓重叠、短暂状态残影"。

### 3.3 要点

| 项 | 内容 |
| --- | --- |
| 色彩 | 瓷 `#D9D6CF`、墨 `#15151A`、敌对光圈 `#FF5A1F`（在瓷面上仅 2.5:1）、三印版 `#00B8D4 / #E0447C / #F4C430` |
| 角色 | 极简原型形体：胶囊、穹、菱、碑、光环面具；辨识度依赖残影效果 |
| 场景 | 釉面砖、剥落、单顶光池 |
| UI | 临床印刷：细体无衬线、套准标与裁切标、圆形工具位 |
| Signal | 网点密度；不稳定 = 印版分离，对齐 = 稳定或护盾解除 |

### 3.4 成本、扩展与风险

- **成本**：低到中。三次偏移绘制加 MULTIPLY 混合，Canvas 可用。
- **扩展**：规则可复用；但"瓷白实验室"难以延伸到城市、档案馆。
- **风险**：
  - 容易被误读为廉价 glitch 风。
  - 品红与敌对橙红在红绿色觉下接近；印版在瓷面上对比度很低（1.9:1）。
  - 大面积亮场在长时间战斗中容易疲劳。
  - 必须提供强度开关（AR-06）。

## 5. 推荐：方向 A · SURVEY INK

**理由（艺术质量与辨识度优先）**

1. **它是一条"视觉规则"，而不只是一种"视觉风格"。** "被观测的才被画出"把 GDB 的核心体验（观察→理解→操纵）直接变成画面语法：玩家每一次 Scan 都在改变画面本身。这是 B 做不到的；C 能做到，但只覆盖"不稳定"一种状态。
2. **可读性最稳。** 明度区分阵营，形状区分种类，唯一红色只给敌对。这一套正好修复审计中最严重的问题：敌我同青、敌人同圆、Boss 与 hunter 同形。
3. **最符合 Canvas 管线和可维护性。** 不依赖 WebGL；新区域只需换材质；AR-03 的"墙地厚度、前后层、随机装饰"可以直接使用独立视觉 RNG。
4. **可以吸收其他两个方向的长处**（每一项都需要你确认）：
   - 吸收 B 的**体量**：墙高与厚度、前景遮挡层、远景巨构剪影，用在 AR-03 的环境叙事上。
   - 吸收 C 的**印版失准**：只作为"不稳定状态"的专用表现，例如 Station Zero 桥梁的 `UNSTABLE`，或 Warden 阶段转换；默认低强度，可关闭。
