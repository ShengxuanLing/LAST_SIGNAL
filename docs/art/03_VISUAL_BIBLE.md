# ART-RENAISSANCE · 视觉规范（Visual Bible）— 方向 A · SURVEY INK

> **状态：方向 A 已确认。** AR-02 用种子 1 的战斗房和 Station Zero 验证本规范。面向全游戏的规格随 AR-03 至 AR-07 的实施继续验证。

## 1. 总纲

**一句话**：被观测的世界才被画出。

**四条规则（违反任何一条都需要设计评审）**

1. **明度分阵营**：执行者与"已知"信息最亮，敌对是深色体块，环境居中。
2. **唯一红色**：朱红只出现在敌对的感知器官（光圈）、敌弹与敌对的瞄准线上。
3. **墨线 = 知识**：骨白墨线只画已经被观测或揭示的东西。墨线的线型表达置信度：实线 = 观察，虚线 = 推测，点线 = 历史。
4. **光有来源**：每个亮点都对应一个世界物体（桅杆灯、中继器、光圈、子弹）。不允许屏幕中心光，不允许无源泛光。

## 3. 可辨识轮廓

| 单位 | 轮廓类 | 世界尺寸（zoom 1，px：宽 × 高） | 屏幕尺寸（zoom 0.8） | 识别要点 |
| --- | --- | --- | --- | --- |
| 执行者 | 竖人形 + 左侧桅杆 | 40 × 64 | 32 × 51 | 最亮体块；桅杆灯 `interact` |
| Drone 经纬仪 | 三脚 + 方头 | 40 × 48 | 32 × 38 | 三条腿；单个圆形光圈 |
| Stalker 钳行体 | 低宽弧 + 前钳 | 56 × 34 | 45 × 27 | 最低最宽；条形光 |
| Hunter 测距风筝 | 悬浮菱 + 侧翼 | 60 × 52（离地 8） | 48 × 42 | 悬浮影子分离；瞄准线 |
| Sentinel 闸门塔 | 竖碑 + 宽底 | 56 × 84 | 45 × 67 | 全场最高的普通单位；百叶眼 |
| Warden 浑天仪 | 环 + 核 + 三足 | 220 × 220 | 275 × 275（Boss 房 zoom 1.25） | 环上冷蓝节点；阶段 = 环脱落 |

**规则**

- 灰度化之后，五类仍然可以区分（A2 第一行即为测试）。
- 新增敌人必须选择一个**新的**轮廓类，或者明确属于某类的变体（例如精英 = 同类加冠或加装甲）。
- 碰撞半径不变（玩家与敌人 0.5 格，Boss 3 格）。可视主体在地面投影上不超过碰撞足迹的约 1.2 倍；Hunter 的翼展可以超出，但必须是视觉上明显的"非实体"部分（细线、半透明）。
- 社区角色（鲸鱼娘等）接入规则：
  - 不修改原图；
  - 统一高度 64px（世界）；
  - 加 `env.ao` 接触阴影椭圆；
  - 外描 1px `ink.known` @ 60%（离屏预合成）；
  - 可选 MULTIPLY 环境色调（Canvas 支持），用于和石墨环境统一。

## 4. 比例与构图

- **网格**：等距 64×32（不变）；墙高 90px（现为 26），墙厚以地板前缘 30px 的"板厚"表达。墙体仍只在烘焙纹理中绘制，碰撞不变。
- **相机**：区间 0.8–1.25 不变。普通房的构图目标是房间约占画面 55–65%，靠房间渲染尺度与前景暗角实现，**不改缩放数值**。
- **文字避让**：
  - 浮字（房名、清房提示）放在屏幕上方 1/5 的固定横带，不再贴在玩家头顶（修复审计 7.2 的遮挡问题）。
  - 伤害数字向上并按照"横向 ±8px × 序号"错开，不覆盖角色头部。
- **核心战斗区**：屏幕中心 480×320 范围内只允许出现角色、子弹、Signal 标注；HUD 与 ECHO 不得进入。

## 6. 层次与光影

**渲染层**（由下到上，括号内为 depth）：

1. **L0 虚空**（-10）：`env.shadow` 加极低频颗粒。
2. **L1 地板烘焙**（-1）：体块 + 墨线（已观测遮罩）+ 油污与 AO。
3. **L2 后墙烘焙**（-1，同纹理）：高 90px，受光面与背光面使用不同渐变。
4. **L3 地面贴花与拾取**（60–70）。
5. **L4 角色**：depth 按等距排序 `= 100 + (wx + wy) * k`，取代现在固定的 100 / 95 / `floor(wy)`。
6. **L5 子弹与命中**（同 L4 排序 +0.5）。
7. **L6 前景遮挡**（例如地板前缘、管道）：玩家位于其后方时 alpha 降到 0.35。
8. **L7 光**：ADD 混合的烘焙光斑——桅杆灯半径约 60px、中继器约 80px、敌对光圈约 24px，跟随世界物体，不锁定屏幕中心。
9. **L8 Signal 标注**（ECHO 视角）：连接线、引线标签、扫描环。
10. **L9 HUD**（500）。

**明度预算**：最亮的 5% 像素只能属于执行者、自发光与闪光；环境的最高明度不超过墨线的 80%。

## 8. 动画规范

**实现方式**：两种手段都兼容 Canvas。

- 程序化帧序列：离屏 Canvas 逐帧绘制，用 `texture.add` 注册帧，再交给 Phaser Animations。
- 变换动画：tween 改 scale / offset / rotation，**不旋转烘焙的阴影**；阴影单独做精灵。

**时钟**：动画时钟必须可以固定，截图与测试时由 `game.step` 推进。

| 状态 | 执行者 | 普通敌人（共性） | Warden |
| --- | --- | --- | --- |
| Idle | 4 帧 / 1.2 s 呼吸；桅杆灯 2 s 慢闪 | 光圈缓慢扫视（±15°）；悬浮单位上下 2px | 环缓慢自转；节点脉动 |
| Move | 6 帧 / 0.5 s，按 8 方向翻转 | drone 三脚交替；stalker 钳腿波动；hunter 侧翼倾斜 | 三足缓步，环保持水平 |
| Attack | 枪口骨白闪 1 帧 + 后坐 2px | **预兆必须先于伤害**：光圈放大 + 朱红瞄准线 ≥ 250 ms（只画在已有 attackTimer 之内，不改数值） | 每个阶段的招式都有不同预兆：冲击波 = 环下沉；激光 = 三条瞄准线；召唤 = 节点外抛 |
| Hit | 外壳朱红描边 60 ms；生命条段闪 | 白色体块闪 60 ms + 墨线碎屑 3–6 条 | 被击节点闪；护盾存在时显示偏转弧 |
| Death | 外壳墨线逐段消失（400 ms）→ 结算 | 体块向内塌陷，光圈熄灭为灰点，残骸墨线留 2 s 后褪成点线（"历史"） | 环逐一断开坠地，核心熄灭，持续 1.5 s。**仅视觉**，`onBossWin` 时序不变 |
| Interaction | 桅杆前倾，青色引线连到目标 | — | — |
| Special | Dash：骨白残影 2 帧 + 地面拖痕；Scan：桅杆发出等距脉冲环 | Sentinel 百叶开合 | 阶段切换：环脱落 + 失准抖动（D3，默认 mid） |

## 9. Signal 表现（按实际机制映射）

| 机制 | 当前实现位置 | 表现 |
| --- | --- | --- |
| 发射 Emit | Station Zero 封锁源、中继器 `ACTIVE` | 源头冷蓝核心 + 3 层同心环，1.2 s 一次外扩 |
| 传播 Propagate | `corridor.ts` 的输出快照 | 冷蓝虚线 + 方向箭头，从源到接收，箭头沿线以 0.6 s 周期滑动 |
| 扫描 Scan | `rules.ts` 的 Scan（半径 12，揭示 8 s） | 桅杆脉冲环 450 ms；被揭示对象 300 ms 内画出墨线；揭示期间显示引线标签；到期褪成点线（历史） |
| 响应 Respond | 门 `SEALED → JAMMED_OPEN`，桥 `TRANSITIONING / STABLE` | 接收器由琥珀变为青；桥面墨线逐格"测绘"出现，与 90 tick 过渡同步 |
| 干扰 Jam | Jam 持续 6 s、冷却 8 s，二者分开显示 | 接收端截断符号；连接线断续；工具位底条（持续）与冷却弧（冷却）分别显示 |
| 衰减 / 失稳 Decay | 桥 `UNSTABLE` 90 tick | 桥面墨线变琥珀并失准偏移；显示倒计时与安全方向箭头 |
| 敌感知 Perception | `corridorGuard` 的共享 / 本地感知、证据 8 s 过期 | 守卫光圈到证据点的朱红虚线；共享断开时，中继到守卫的连线显示断开 |
| 能量 Energy | 上限 100，+5/s，Jam 消耗 25 | 能量条在 25 / 50 / 75 处有刻度；恢复时有斜纹流动 |
| 主游戏 | **尚无 Signal 机制** | AR-02 / AR-04 只做 Scan 式的"墨线揭示"环境效果与 Boss 节点视觉，**不新增机制** |

## 10. 视觉 RNG、确定性、性能与无障碍

**视觉 RNG**
- `visualRng = new RNG(hash(map.seed, roomId, 'VIS'))`。
- 只用于装饰、磨损、喷码、粒子抖动。
- **禁止**调用 `World.rng` 或 `Math.random`。
- 不影响 `isWalkable`、刷怪点、掉落和检查点的 `rngState`。

**纯视觉**
- 所有动画与特效只读取游戏状态，不写回游戏状态。
- 结构化 Game State 仍是唯一权威。

**测试友好**
- 粒子、闪光、扰动都受全局"视觉扰动"开关控制，截图时可以全部关闭。
- 动画时钟随 `game.step` 推进。

**性能预算**（1280×720，i7-10510U 基线）
- 每帧 `game.step` 的 CPU p95 不得高于基线 +4 ms。
- 显示对象 ≤ 250。
- 粒子 ≤ 160。
- 每帧重绘的 Graphics ≤ 3 个。
- 烘焙纹理单张 ≤ 4096²。

**质量档**（AR-06）
- Low：无光斑、无粒子、无失准。
- Medium：默认。
- High：仅在 WebGL 获批后加入 FX。

**无障碍**
- 设置项：关闭强闪 / 震动 / 失准；高对比 HUD。
- 颜色之外还有线型与形状冗余编码。
- 最小文字 12px。
