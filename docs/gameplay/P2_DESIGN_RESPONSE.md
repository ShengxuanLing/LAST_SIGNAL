`rejectLocalEchoProposal`, `echoCooperationOptIn` (default OFF, old save OFF), the
local Pause page/switch/audit, the same `EchoController` in the formal headless

connection is reachable post-P0, but no model-driven E2E has been run and P2 does
not call a model from core). P0's historical real-LLM BLOCKED record stands.
