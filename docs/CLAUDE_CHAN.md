# Claude-chan 角色外观

在主菜单右侧点击角色名称，循环到 Claude-chan。选择会保存在当前浏览器中，新开局和继续游戏都会读取。

角色直接使用 CrossPet 在 GitHub 发布的三张透明 WebP。正面取自 `idle.webp`，向左和向右分别使用 `busy_left.webp` 和 `busy_right.webp`。游戏中的文件只改名，绘图内容保留原样。上下移动沿用正面。

- 素材由 CrossPet 制作，角色设定源自社区的 Claude 娘，原始橙发持书形象由 ZipZipPipe 设计。 [CrossPet 固定版本素材](https://github.com/lokicorvus/crosspet/tree/8954eb8f7f69fcfb8d35e9deceeb78e10c804402/characters/claude) · [原始设计](https://www.bilibili.com/opus/1233069202138464289)
