# GDD-02 — 首切片因果链

本文件应用[主规则](REALITY_ENGINEERING_RULES.md)，与[测试规格](GDD_02_TEST_SPEC.md)配套。除登记册中明确批准的 D1/D2 范围外，以下详细机制均为**建议冻结**；数值引用主规则 §6 的 **Prototype Tuning Values — 原型调参初值**。本轮没有实现或玩法验收。

## 1. 入口与固定模板边界

首切片为 Station Zero — The Broken Door。建议独立入口加载固定模板 MapData，不调用 MapGenerator.generate/assignRoles，继续复用 World、坐标变换、战斗与HUD。当前 GameScene 只接收 seed/resume 并直接生成随机地图，因此固定模板供给是未来接口提案，不是现成能力。

| 标识 | 逻辑位置 | 规则用途 |
| --- | --- | --- |
| R0 | 苏醒舱 | 移动、战斗基础、Scan与ECHO初次观察 |
| R1 | 观测实验室 | 对照门与受封锁门，验证接收控制 |
| R2 | 失稳走廊 | 同一空间内战斗和Signal两种解法 |
| R3 | 共识核心 | Warden及其Relay护盾源 |
| R4 | 结尾界面/撤离表现 | 击败Warden且玩家存活后才能进入，不是额外战斗房 |

R0–R4 只是逻辑 ID，四个主房间加结尾界面，不规定实际尺寸或新增 RoomKind。精确布局、敌人数量与剧情留 GDD-03。模板先校验主规则 §3 的安全约束。切片采用 §11 的独立命名空间，禁止覆盖原版/economy run，补给终端不并入切片。

## 2. 观测实验室九步因果链

| 步 | 输入与动作 | Signal/物理结果与反馈 | 失败/恢复与证据 |
| --- | --- | --- | --- |
| 1 | 玩家尝试两扇相同外观的门 | 对照门无封锁可普通打开；谜题门因SEAL接收关闭 | 普通开门返回E_LINK_UNAVAILABLE，无扣费 |
| 2 | 玩家主动Scan | 范围/LOS内揭示封锁载波、合法连接与当前接收，脉冲扣一次10 | 不足则在安全区等待，空扫合法但返回未发现 |
| 3 | 玩家或ECHO提出假设 | ECHO可报告载波活动，假设与观察事实分开 | 不要求先点击指定台词才能操作，不自动给完整答案 |
| 4 | 玩家对接收器Jam | 25 Energy；当前封锁接收被压制，源仍存在 | 非法/不足/冷却中零扣费，可换新请求再试 |
| 5 | 观察结果 | 门JAMMED_OPEN，真实通行性改变 | 记录来源、操作、状态变化，不以动画代替碰撞 |
| 6 | 玩家通过 | 门区占位为权威位置快照 | 即将到期仍有占位保护 |
| 7 | Jam到期 | 移除效果并恢复接收；当前源仍在才重新得到SEAL | 不重造已失联源，不回滚位置/HP/已有弹丸 |
| 8 | 当前设备求解 | 有封锁且有人时SAFE_PENDING_CLOSE，空出后延迟关闭；无封锁按当前意图 | 一直占位只延后关闭；不能手动绕有效封锁 |
| 9 | 验证理解 | 记录是否能预测到期、占位和断源三种不同结果，再做同构迁移判断 | 操作日志不等于理解；过期隐藏字段需再次Scan才能刷新 |

这是一条正常教学流程。无提示试玩可以先实验再解释，不强制每个人先Scan。ECHO事实反馈不得把假设自动确认为剧情真相。门开之后仍要等待合法到期/恢复事件验证因果闭环。

## 3. 失稳走廊路线 A — 战斗后建立通路

| 项目 | 完整合同 |
| --- | --- |
| 前置条件 | relay初始OFF，有本地供电与两岸开关；桥UNAVAILABLE；玩家可在此岸用常规武器清敌 |
| 操作 | 先清本地威胁，再接近控制器手动ON，等待建立预警结束后过桥 |
| Signal变化 | emitOn=true，同一提交将输出送桥和共享感知连接 |
| 环境变化 | 桥UNAVAILABLE→TRANSITIONING→STABLE，有真实承重 |
| 敌人反应 | 仍存活的关联敌人可接收共享信息；已清除敌人不复活。本地视觉在relay OFF时也可工作 |
| 失败情况 | 战斗受伤/死亡，建立中断电，过桥中误关设备 |
| 恢复方法 | 死亡走正常重开；非致命失稳送岸，任意次数可用本地开关恢复，非法操作零扣费 |
| 完成条件 | 玩家经承重桥到达对岸，进入R3；路线不消耗Signal Energy |

开启中继器导致桥与共享感知同时改变，不能按顺序“先过桥后激活敌人”。清敌在前只是玩家避免副作用的一种策略。

## 4. 失稳走廊路线 B — 信息诱导后穿越

| 项目 | 完整合同 |
| --- | --- |
| 前置条件 | 同一模板/同一走廊，与路线A可中途切换；提供遮挡和合法诱饵点，保证玩家能离开局部可见范围 |
| 操作 | 从遮挡侧投Decoy，使敌人没有可见玩家但能接收诱饵；必要时对关键Enemy Link使用Jam；再开启relay并过桥 |
| Signal变化 | Decoy产生可接收源；Jam屏蔽新信息；relay ON恢复共享链路，但仍受该接收器Jam约束 |
| 环境变化 | 同样建立桥梁，不依赖杀光敌人 |
| 敌人反应 | 诱饵实际胜出才调查；可见玩家始终优先；Jammed只按旧位置调查；已有弹丸继续飞行 |
| 失败情况 | 诱饵无LOS/超距、玩家暴露、Jam太早结束、自己Jam relay导致桥失稳 |
| 恢复方法 | 撤回安全区等Energy/冷却，换新请求再试；可转路线A；桥预警期间离开或恢复供电，到期送岸 |
| 完成条件 | 玩家在仍有活敌时合法越桥进入R3，日志记录敌人接收信息变化，不靠强制眩晕或清场 |

此路线的出口不能复用“必须清怪才产生传送门”作为唯一条件。切片由桥可通行与玩家到岸触发下一房间；未击杀敌人留在原房间，回返仍按合法信息行动。现有World自动清房/刷怪/传送门需要未来适配，不能声称已支持这一路径。

## 5. ECHO、观察与人类权限

ECHO只使用主规则 §10 的本地信号与已观察事件。门的普通外观不直接泄漏SEALED；relay完整依赖图和Boss未触发阶段始终隐藏。详细护盾来源必须Scan确认。ECHO提示绑定真实变化，不作为世界状态权威。

本轮只定义受限观察、建议和失败降级接口。至少一次合理分歧，例如想继续观察信号与玩家想立即前进，由GDD-03决定具体台词和事件。ECHO不能随机拒绝合法操作，也不能代玩家提交结尾选择。外部LLM未连接时，预定义逻辑与人类操作构成完整流程；未来Agent故障降级Mode A，已合法产生的世界状态继续按规则运行。

## 6. Warden与结尾

| 步骤 | 条件与行为 | 可测试结果 |
| --- | --- | --- |
| 进入R3 | Warden存活，玩家存活 | 结尾锁定，公开当前阶段一，不公开未来阶段 |
| 普通战斗路线 | 不使用Scan/Jam/Decoy攻击Boss | 护盾ON仍至少2伤害，HP可降到0，无强制Signal门槛 |
| Signal辅助路线 | Scan发现护盾合法来源，再Jam该Relay | 输出OFF，护盾倍率由0.5到1.0；同输入伤害对照有实质收益 |
| 场地压力 | 若GDD-03使用附加压力节点，其类型仍为Relay/Enemy Link | 输出按同一因果快照生效，不创造第五目标类或隐藏脚本捷径 |
| 非法操作 | 直接Jam桥/自由地形，普通交互关闭维护封闭Boss节点 | 明确失败、零扣费，不改变Boss HP或阶段 |
| Boss死亡 | 玩家存活且本tick未同时死亡 | 胜利会话只结算一次，解锁R4；不需要撤离绕战斗 |
| 玩家死亡/同时死亡 | 失败优先 | 结尾保持锁定，正常失败与重开 |
| 结尾选择 | 玩家选择两个合法不透明选项之一 | 只有持久写入成功才显示已保存并退出选择；失败可重试 |
| 下一局 | 读取最后一次成功提交的选择 | 模板呈现其对应差异；本局不可撤销，下一局可再次选择 |

两种选项内容、具体持久字段和可观察差异的美术/叙事表现留GDD-03。本轮只保证写入幂等、失败不伪报保存、清run不清持久结果、旧模式进度隔离。

## 7. 验收与未决边界

[测试规格](GDD_02_TEST_SPEC.md)应覆盖门全链、走廊两路线、普通/Signal辅助Boss胜利、失败重开、选择与下一局后果、无LLM完整流程及未来断线降级。单测验证状态机和确定性，浏览器用真实操作走流程，无提示试玩记录预测与迁移证据。当前没有运行这些未来功能测试。

| 范围 | 本轮给出的约束 | GDD-03或实现前仍需确认 |
| --- | --- | --- |
| 门/桥安全 | 主规则状态机和有界恢复 | 精确几何、门区与岸点位置 |
| 走廊 | 同一空间两种机制解法 | 敌人布置、遮挡、时长是否足够 |
| Boss | 击败必需、护盾真实依赖、普通可赢 | 场地节点配置和战斗平衡 |
| ECHO | 权限与事件合同 | 台词、分歧表现、提示强度 |
| 选择与存档 | 独立命名空间、成功写入、幂等与下一局接口 | 选项内容、扩展字段和迁移ADR |
| 验收 | 可执行测试规格提案 | 关卡fixture、试玩安排及最终验收批准 |

本轮不修改GDB、旧Signal设计或源码。D1覆盖旧撤离候选，D2限制高级协议，Jam信息接收语义和5每逻辑秒恢复均是待确认细则。新旧阶段编号、完整世界真相与全套身份记忆不在GDD-02内解决。
